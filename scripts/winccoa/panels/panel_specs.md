# CLI_TEST panel specs

`.pnl` files are WinCC OA's own GEDI-editor format and can't be authored
as plain text - these specs are the build instructions for whoever opens
GEDI in CLI_TEST, one section per panel from SKILL_winccoa.md §7.1. DP
bindings reference the tags generated by `src/topology/equipment_catalog.py`
(exported to `tag_list.csv` by `gen_mock_csv.py`).

Conventions used throughout:
- Bus = thick horizontal line, branches = right-angle vertical/horizontal only (no diagonals/curves).
- Breaker symbol = standard switchgear icon, colored by `<name>_STATUS` (green=closed/normal, red=open, per the reference screenshots).
- Transformer symbol = two circles (Y/Δ).
- Every equipment gets a value box bound via `dpConnect`: `POWER(kW) / VOLTAGE(V) / CURRENT(A) / PF`.
- Screen labels use the hyphenated form (`GCB-3A1A`); DP bindings use the underscored form (`GCB_3A1A`).

---

## 1. `gis_154k.pnl` — 154kV GIS overview

Reproduces `sample image/154k_1.png` + `154k_2.png` layout: two horizontal
bus rows (A-bus, B-bus), each row hosting the GCB groups from
`equipment_catalog.GIS_GROUPS`.

- Top bus bar (A-bus): breakers `GCB-3A1{A,M,B}` … `GCB-3A5{A,M(,B)}` hung
  off it left-to-right, in the order 3A1, 3A2, 3A3, 3A4, 3A5. Use the
  per-group `stages` list from the catalog (3A3/3A4 have no B - draw only
  A/M for those two).
- Bottom bus bar (B-bus): `GCB-3B1{M,B}`, `GCB-3B2{A,M,B}`, `GCB-3B3{M,B}`,
  `GCB-3B5{A,M,B}` (3B4 not in the catalog - leave a gap, don't fabricate it).
- Two vertical tie breakers between the bus rows: `TIE-3ABB1`, `TIE-3ABA1`.
- Each confirmed group (has a value box in the source screenshot) gets the
  standard MW/kV/A/PF box bound to `GCB_<name>_POWER/VOLTAGE/CURRENT/PF`.
- Do NOT add the "EMG T/L" / "고덕2-삼성P3#1 T/L" boxes from the reference
  screenshots - those are upstream-utility interconnection flags, out of
  the plant EQP_NAME convention this project's topology graph uses.

## 2. `bank_3F11.pnl` — 3F11 bank detail

Reproduces `sample image/6.6_1.png`. Top-to-bottom:

1. `BTR_3F11A OLTC` / `BTR_3F11B OLTC` boxes (tap/load%/temp).
2. MAIN VCB row: `VCB_3F11A`, `VCB_3F11B`, with `DIS_3F11AB` / `TIE_3F11BA`
   between them.
3. K-span row: `VCB_3F11AK`, `VCB_3F11BK`, `VCB_3F11CK`, `VCB_3F11DK`, plus
   bus nodes `BUS_3US1AK`, `BUS_3US1CK` (topology only, no value box).
4. Q-span row: `VCB_3F11AQ`, `VCB_3F11CQ`, and the isolated `DIS_3F11AD`.
5. Feeder grid: two rows of 15, branch A (`VCB_3F11A1`..`A15`, spare `AC`)
   and branch C (`VCB_3F11C1`..`C15`, spare `CC`).
6. Below each feeder: its `LTR_3F11<branch><n>` (Y/Δ symbol, temp boxes for
   BOTH points `_TEMP_C` and `_TEMP_W` - the source screen shows exactly
   two, not three) and `ACB_3F11<branch><n>` output box.
7. `ECB_3F11AC`, `ECB_3F11BC` tie breakers at the 220V level, per
   `sample image/6.6_3.png`.

## 3. `bank_3F12.pnl` (optional, same template)

Same layout as `bank_3F11.pnl` but for 3F12. Its K-span uses letters
`C,D,E,F` (not `A,B,C,D` - confirmed different from 3F11 on screen), and
its feeder branches (`B`, `D`) and Q-span letters are `inferred` in the
catalog, not photographed - mark this panel "미검증 레이아웃" until an
actual 3F12 feeder-row screenshot or TN_CM_EQP query confirms it.

## 4. `overview.pnl` — plant overview

Condensed single-screen version: 154kV GIS row (bus + GCB groups,
collapsed to STATUS-colored breaker icons only, no value boxes) feeding
down into the 8 BTR banks (3F11A/B … 3F14A/B) feeding down into 8
abbreviated MAIN VCB blocks. Click-through navigation to `gis_154k.pnl` /
`bank_3F11.pnl` / `bank_3F12.pnl` on each block.

## 5. `trend.pnl` — tag trend viewer

- A tag picker (combo/tree) populated from `tag_list.csv` (group by
  `prefix` → `eqp_name` → `quantity`).
  Use WinCC OA's standard `TrendControl` widget bound at runtime to the
  selected DP's `_online.._value` element (or the archived value if
  SVR_TEST is configured with `dpSetTimed`/history archiving).
- Time-range selector; default window = last 30 minutes.

## 6. `alarm.pnl` — alarm list

- Standard `AlarmControl` widget filtered to `STATUS` tags (from
  `equipment_catalog.APPLICABLE_QUANTITIES`, prefixes GCB/BTR/VCB/ACB/ECB/
  TIE/DIS all carry STATUS) plus any threshold alarms configured on FLOAT
  tags (e.g. PF outside ±[90,100], TEMP > 60°C).
- Columns: timestamp, tag, label, old→new value, ack state.

---

## Build order

1. `gis_154k.pnl` and `bank_3F11.pnl` first (fully confirmed equipment -
   least risk of drawing something that doesn't exist).
2. `trend.pnl` and `alarm.pnl` (generic, DP-list-driven - no per-bank
   layout work).
3. `overview.pnl` last (needs the other panels' navigation targets).
4. `bank_3F12.pnl` whenever its layout gets confirmed - see the note in
   section 3.
